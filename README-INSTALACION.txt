HYX — INSTRUCCIONES DE INSTALACIÓN

Este ZIP contiene una PWA (aplicación web progresiva), no un APK ni una app publicada en la App Store.

PARA INSTALAR EN ANDROID O IPHONE
1. Publica todos los archivos del ZIP juntos en un sitio HTTPS (por ejemplo, GitHub Pages, Netlify o Cloudflare Pages).
2. Abre esa dirección desde el teléfono.
3. Android: Chrome > menú ⋮ > Instalar aplicación / Añadir a pantalla de inicio.
4. iPhone: Safari > Compartir > Añadir a pantalla de inicio.
5. Abre HYX una vez con conexión para que guarde los recursos. Después funciona sin internet, con limitaciones del sistema para cronómetros en segundo plano.

PARA PROBAR SIN PUBLICAR
Abre el archivo HYX_movil_sin_instalar.html en un navegador. Esta versión sirve sin conexión, pero no se instala como una PWA.

NOTA: Las rutinas se guardan en el navegador y dispositivo donde las creas. Haz una copia del ZIP, no borres los datos del navegador. El uso del sonido y las notificaciones puede depender del dispositivo.
